# 🎨 AI Headshot Pro - التعليمات بالعربية

تطبيق لإنشاء صور شخصية احترافية باستخدام الذكاء الاصطناعي من Google Gemini

## 🚀 البدء السريع

### الخطوة 1: الحصول على مفتاح API مجاني

1. اذهب إلى **[Google AI Studio](https://aistudio.google.com/apikey)**
2. سجل الدخول بحساب Google الخاص بك
3. انقر على **"Get API Key"** أو **"Create API Key"**
4. انسخ المفتاح

### الخطوة 2: تفعيل المفتاح

افتح ملف `.env` واستبدل `your_api_key_here` بالمفتاح الخاص بك:

```bash
VITE_GEMINI_API_KEY=AIzaSyAbc123... # ضع مفتاحك هنا
```

### الخطوة 3: تشغيل التطبيق

```bash
npm run dev
```

## 🔧 استكشاف الأخطاء

### خطأ 429 - تجاوز الحصة

**المشكلة:** `Too Many Requests` أو `Quota Exceeded`

**الحل:**
1. احصل على مفتاح API جديد من [Google AI Studio](https://aistudio.google.com/apikey)
2. كل حساب Google جديد يحصل على حصة جديدة
3. انتظر حتى يتم تجديد الحصة (يومياً)

### المفتاح لا يعمل

**تأكد من:**
- ✅ المفتاح يبدأ بـ `AIzaSy...`
- ✅ اسم المتغير `VITE_GEMINI_API_KEY` (يجب أن يبدأ بـ VITE_)
- ✅ أعد تشغيل خادم التطوير بعد تعديل `.env`
